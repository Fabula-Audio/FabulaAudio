# Fabula Audio 4.21 — fixed31

## Задача
Унифицирован внешний вид основных кнопок действий во всём приложении.

## Что изменено

### Единый цвет основных кнопок
Основной цвет кнопок теперь задаётся отдельным ресурсом:

- `fabula_button` — `#5B7553` (Dusty Olive)
- `fabula_button_text` — `#C3E8BD` (Tea Green)

Основные кнопки используют этот цвет и сохраняют скруглённую форму Material 3, как кнопки режимов на главном экране.

### RecordTextActivity
Приведены к единому стилю:

- «Загрузить файл (.txt, .docx)»;
- «Вставить из буфера обмена»;
- «Далее»;
- «Записать»;
- «Стоп»;
- «Прослушать»;
- «Перезаписать»;
- «Оставить результат»;
- «Склеить и сохранить».

### MainActivity
Приведены к единому стилю:

- «ВЫБРАТЬ ТРЕК»;
- `×6`, `×144`, `×432`;
- «Плей»;
- «СТОП»;
- «ПРОСЛУШАТЬ РЕЗУЛЬТАТ»;
- «СОХРАНИТЬ РЕЗУЛЬТАТ»;
- «Выход на главную»;
- «Выход из приложения».

Выбранный режим ускорения по-прежнему визуально отмечается рамкой, но фон кнопки остаётся тем же `#5B7553`.

### HomeActivity
Кнопки основных режимов и «Выход из приложения» используют тот же единый стиль.

Кнопки шапки `?` и `⋮` намеренно оставлены нейтральными, чтобы сохранить их роль как служебных элементов шапки и эталон главного экрана.

### AlertDialog
В диалогах приложения кнопки `OK`, `Закрыть`, `Отмена`, `Далее`, `Удалить`, `Сохранить`, `Выбрать`, `Выход на главную` и другие действия получают:

- фон `#5B7553`;
- текст `#C3E8BD`;
- скруглённые углы.

`UpdateManager.kt` не изменялся — это было отдельным жёстким ограничением задачи. Поэтому его диалог обновления также не подвергался прямому изменению.

## Архитектурное изменение
Добавлен небольшой внутренний файл:

`app/src/main/java/com/fabula/audio/UiStyles.kt`

Он содержит два переиспользуемых метода:

- `styleActionButton()` — стиль основной кнопки;
- `styleDialogButtons()` — стиль кнопок AlertDialog.

Новых внешних зависимостей не добавлено.

## Что НЕ менялось

- `UpdateManager.kt`;
- аудио-логика;
- FFmpeg-команды;
- логика ускорения ×6/×144/×432;
- запись и склейка аудио;
- автообновления;
- зависимости Gradle;
- `gradle.properties`;
- версия приложения: `4.21` / `versionCode 21`;
- splash/icon;
- package `com.fabula.audio`.

## Проверка
Проверено статически:

- старые фиолетовые/лавандовые HEX-цвета в `app/src/main` не используются;
- код основных кнопок больше не использует `fabula_yellow` / `fabula_gold_selected`;
- `UpdateManager.kt` полностью совпадает с исходным файлом из входного архива;
- XML разметка содержит единый `fabula_button` для основных кнопок.

Полную Gradle-сборку в текущем изолированном окружении выполнить не удалось: Gradle Wrapper попытался скачать Gradle 8.7 с `services.gradle.org`, но DNS/интернет в окружении недоступен. Поэтому `BUILD SUCCESSFUL` не заявляется.
