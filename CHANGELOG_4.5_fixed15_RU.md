# FabulaAudio 4.5 fixed15 — changelog

## app/src/main/java/com/fabula/audio/MainActivity.kt
- Убран двухпанельный экран, списки треков и весь код `DocumentFile`.
- Убран Photo Picker, ImageView, обработка обложек и `FABULA_IMG`.
- `ACTION_OPEN_DOCUMENT` используется для выбора одного аудиофайла. Последнее выбранное расположение выбранного документа передаётся в системный picker через `DocumentsContract.EXTRA_INITIAL_URI`, чтобы picker возвращался к той же папке.
- Выбранный файл и папка сохранения запоминаются в SharedPreferences.
- Папка сохранения выбирается через `ACTION_OPEN_DOCUMENT_TREE`; право записи закрепляется через SAF.
- `×6`, `×144`, `×432`, `Все вместе`; выбранный режим подсвечивается золотистым.
- `Все вместе` выдаёт строго один итоговый файл.
- Очистка: `adeclick` + двухточечная АЧХ `783.59459/+6.2578812`, `1372.3845/-47.656158`. Запятые внутри формулы FFmpeg экранированы.
- ×6: `atempo=2.0,atempo=2.0,atempo=1.5` + одна конкатенация 6 копий.
- ×144: `atempo=2.0,atempo=2.0,atempo=2.0,atempo=3.0` + одна конкатенация 24 копий.
- После ×144 применяется `afftdn=nr=6:nf=-50:tn=1:tr=1`, затем ×432. Макрос `NoiseReduction` не используется.
- ×432: `atempo=2.0,atempo=1.5` + одна конкатенация 3 копий.
- После импорта и каждого FFmpeg-шага ведётся `FABULA_DUR`; после конкатенации проверяется отклонение до 1 секунды.
- Оставлен фоновый `Thread`, `q(...)`, `check(ReturnCode.isSuccess(...))`.
- Добавлен единый `MediaPlayer` для результата, кнопки «Прослушать результат» и «Стоп».
- Ползунок громкости меняет громкость MediaPlayer в реальном времени и применяется через FFmpeg `volume` перед сохранением.
- Сохранение выполняется напрямую в выбранное SAF-дерево; создаётся один FLAC с введённым именем.
- Название обязательно, описание необязательно. Описание передаётся в FLAC `comment`; при ошибке записи метаданных выполняется fallback без тега и создаётся `.txt`.
