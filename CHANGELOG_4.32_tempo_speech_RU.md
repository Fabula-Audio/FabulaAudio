# Fabula Audio 4.32 — исправление цепочки темпа по трассировке Audacity

## Изменения
- Этап ×144 теперь склеивает 6 копий фрагмента после ускорения ×24. В присланной трассировке Audacity после `ChangeTempo:Percentage="2300" SBSMS="1"` следуют пять команд `Paste`, то есть всего шесть фрагментов.
- Ожидаемая длительность ×144: примерно исходная длительность / 4. Для WAV длительностью 107.674 с это около 26.9 с.
- Этап ×432 строится из ×144: ускорение ×3 и три копии. Ожидаемая общая длительность остаётся около 26.9 с.
- UI, ресурсы, обработка подготовки и структура проекта не менялись.

## Важное ограничение алгоритма
Приложение по-прежнему использует FFmpeg `atempo`, а не Audacity SBSMS. Исправление восстанавливает число копий и ожидаемую длительность, но не гарантирует идентичное тембровое звучание. Для полного совпадения с `ChangeTempo ... SBSMS=1` нужна интеграция и проверка native `libsbsms` через JNI/NDK.
