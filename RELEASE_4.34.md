# Fabula Audio 4.34

Версия 4.34 / versionCode 35. Добавлена кнопка «Исходный код» в окне
«О приложении и лицензиях». Сохранены тексты лицензий и уведомления библиотек.
Аудиоалгоритмы и настройки обработки не изменялись.

Исходный код: https://github.com/Fabula-Audio/FabulaAudio
Лицензия оригинального кода: GNU GPL version 3 only.
Для Android 8.0 и новее, ARM64.

Для сайта: разместите APK и ZIP соответствующих исходников рядом.
Перед публикацией обновите GitHub файлами этой версии.
Удаление старых APK с сайта не меняет подписи и данные установленных приложений.
