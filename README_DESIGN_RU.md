# Что изменено по вашей новой схеме

## Главное изменение
После полного завершения ускорения до **144×** приложение не должно сразу выполнять шумоподавление без выбора пользователя.

Появляется выбор:

- **Автоматически убрать шумы** — приложение применяет автоматическое FFT-шумоподавление.
- **Перейти к ручной очистке** — открывается увеличиваемая дорожка для точной работы с фрагментами.

## Ручная очистка
В дизайне предусмотрены:

- масштаб дорожки;
- выделение участка;
- «Заглушить выбранный фрагмент»;
- «Удалить выбранный фрагмент»;
- отмена последнего изменения.

Это сделано именно под задачу, которую вы показали на скриншоте Audacity: сначала получить сильно ускоренную дорожку, затем работать с короткими шумными участками максимально точно.

## Для 432×
Последовательность задумана так:

`исходник → 6× → 144× → очистка → 432×`

То есть очистка происходит **до финального 3×**, если выбран режим 432×.

## Технический статус
В этой версии новая последовательность и интерфейс уже заложены. Интерактивная waveform-разметка с реальным выделением временного диапазона и применением FFmpeg `atrim/concat` отмечена как следующий этап, чтобы не выдавать прототип за полностью готовый аудиоредактор.
