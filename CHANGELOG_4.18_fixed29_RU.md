# FabulaAudio 4.18 fixed29 — changelog

## Изменённые файлы

### `app/build.gradle`
- `versionCode`: 18 → 19.
- `versionName`: `4.17` → `4.18`.
- Зависимости не менялись.

### `app/src/main/java/com/fabula/audio/RecordTextActivity.kt`
- Убран пункт меню и кнопка меню с экрана записи: меню больше не требуется.
- Перед сохранением добавлен диалог «Сохранение записи» с полями «Название записи» и «Комментарий».
- После «Далее» системный выбор папки открывается каждый раз заново. Старый сохранённый путь не используется.
- В выбранную папку сохраняются аудио и одноимённый `.txt` с названием, комментарием, датой создания и списком фрагментов.
- Имя аудио санитизируется: `\ / : * ? " < > |` заменяются на `_`.
- При пустом названии используется `fabula_zagotovka_YYYY-MM-DD_HH-mm-ss.m4a`.
- Диалог успеха получил кнопки «Выход на главную» и «Закрыть».
- Существующая запись, `.docx`-парсинг, FFmpeg concat и остальные функции режима сохранены.

### `app/src/main/java/com/fabula/audio/MainActivity.kt`
- Добавлена только кнопка «Выход на главную», которая завершает текущую Activity.
- Существующая функция выхода через `exit_splash.png` не изменена.

### `app/src/main/res/layout/activity_main.xml`
- Нижняя панель вынесена за пределы ScrollView.
- Добавлены две фиксированные снизу кнопки: «Выход на главную» и «Выход из приложения».

### `app/src/main/java/com/fabula/audio/HomeActivity.kt`
- Внизу главного экрана добавлена кнопка «Выход из приложения».
- Используется та же 3-секундная immersive-заставка `exit_splash.png` и полное завершение процесса.

## Не изменялось
- `UpdateManager.kt`.
- `AboutDialog.kt`.
- Иконка и `exit_splash.png`.
- Палитра.
- Логика квантования ×6/×144/×432, FFmpeg и `FABULA_DUR`.
- `.docx`-парсинг.
- Существующие зависимости.
- Gradle 8.7 / JDK 21 / targetSdk 35 / minSdk 26.
- Новые зависимости не добавлялись.
