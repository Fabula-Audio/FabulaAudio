# FabulaAudio 4.12 fixed22 — точечные изменения

Дата: 2026-09-30

Эта версия содержит **только три запрошенных изменения**. Аудиологика, обработка, конкатенация, шумоподавление, живое переприменение, предупреждение, меню шапки, выход с заставкой и сохранение не изменялись.

## 1. `app/src/main/res/layout/activity_main.xml`

Изменена только подпись кнопки `@+id/playButton`:

- было: `ПРОСЛУШАТЬ ОРИГИНАЛ`
- стало: `Плей`

Поведение кнопки и её обработчик не изменялись.

## 2. `app/src/main/res/values/colors.xml`

## 3. `app/src/main/java/com/fabula/audio/MainActivity.kt`

### Строка статуса после выбора трека

Изменено только пользовательское упоминание кнопки:

- было: `Трек выбран. Нажмите «Прослушать оригинал» — воспроизведение не запускается автоматически.`
- стало: `Трек выбран. Нажмите «Плей» — воспроизведение не запускается автоматически.`

Обработчик `playCurrentStage()` не изменялся.

### `showInstructions()`

Полностью заменено только содержимое переменной `val text = """..."""` на текст, предоставленный для версии fixed22. Структура `val text = """..."""` и последующий `ScrollView + TextView + AlertDialog` сохранены.

## Проверка неизменности логики

Проверено сравнением файлов с исходным архивом:

- `activity_main.xml` — изменена только строка `android:text` у `playButton`.
- `colors.xml` — изменены только восемь указанных hex-значений.
- `MainActivity.kt` — изменён текст инструкции и два пользовательских упоминания/строка статуса; обработчик `playCurrentStage()` не менялся.
- Другие файлы проекта не изменены.
- `currentResultFile = file` осталось единственным положительным присваиванием.
- Цепочка `×6 / ×144 / ×432` осталась без изменений.
- `ensureStage(currentStage)` в сохранении не добавлялся.
- В архиве сохранены существующие зависимости, включая `com.arthenica:smart-exception-java`.

4. Выбрать трек → нажать **«Плей»**: поведение воспроизведения осталось прежним.
5. Проверить обработку ×6 → ×144 → ×432 и сохранение результата.
