# Сборка FabulaAudio 4.32 — исправленный CMake

Это исходный проект FabulaAudio Android 4.32 из переданного архива. Изменён только файл `app/src/main/cpp/CMakeLists.txt`: пути к исходникам SBSMS заданы относительно каталога CMake, добавлены проверки обязательных исходников и явно включён стандарт C++17.

Логика обработки аудио, Kotlin/Java, Gradle-зависимости и структура приложения не изменялись.

## Открытие

1. Распакуйте архив полностью.
2. В Android Studio выберите **Open** и укажите каталог `FabulaAudio_Android_4.32_tempo_speech` (внутри находятся `settings.gradle` и `gradlew`).
3. Дождитесь Gradle Sync.
4. Выполните **Build > Make Project** или запустите сборку `:app:assembleDebug`.

Каталоги `build`, `.cxx`, `.gradle`, `.kotlin` и `.local-build`, созданные предыдущими сборками/локальной средой, намеренно не включены: Gradle и CMake создадут их заново. Включены исходники приложения, нативные исходники SBSMS, Gradle wrapper и файлы конфигурации.

Примечание: архив подготовлен, но успешная сборка в вашей Android Studio/с установленным Android SDK этим фактом не подтверждается.
