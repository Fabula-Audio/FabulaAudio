# Исходники сторонних библиотек

Папки ffmpeg-kit-audio-8.1.7, smart-exception-java-0.2.1 и
smart-exception-common-0.2.1 содержат распакованные исходные Maven-дистрибутивы.
Исходные заголовки copyright и лицензий сохранены.

В native лежат нетронутые исходные архивы конкретных версий. Их происхождение
и SHA-256 перечислены в ../DEPENDENCY_MATERIALS.json и NATIVE_SOURCES.json.
Архив ffmpegkit-v8.1.7.tar.gz содержит обвязку, скрипты, патчи и upstream
инструкции. Для этой зависимости предназначена папка android-8.1-lts.
Не подменяйте её ветками 6.0 или 7.1 из того же архива.

Для изучения распакуйте архивы через файловый менеджер. Для сборки native
библиотек разработчику нужны Android NDK r27c (как у поставщика), Linux и
утилиты из upstream workflow. Для сборки самой Fabula Audio используется
NDK 26.3.11579264: это отдельная сборка собственной SBSMS-обвязки.

При подготовке native-рабочего дерева внешние компоненты размещаются в
android-8.1-lts/src/<имя-компонента>; Abseil — в src/libilbc/abseil-cpp,
gnulib — в src/libiconv/gnulib, gnu-config — в src/config.
Соответствие имён и версий задано scripts/source.sh в исходном архиве.
Обвязка рассчитывает на Git-метаданные и местами выполняет git submodule;
одной распаковки tar.gz недостаточно для запуска неизменённых upstream
скриптов. При воспроизведении используйте checkout соответствующих тегов и
закреплённых подмодулей либо адаптируйте загрузчик к локальным архивам,
сохраняя внесённые изменения. Исходные файлы для этих checkout вложены.

Точная строка configure извлечена из используемой ARM64 библиотеки и сохранена
в metadata/ffmpeg-binary-configuration.txt. Исторические абсолютные пути
/home/runner/... в ней относятся к CI поставщика; замените их своими путями.
Независимое воспроизведение native-сборки ещё не проводилось.

Старый res/raw/source.txt из AAR сохранён дословно среди лицензий для
прослеживаемости. Он ссылается на прежний Arthenica и не является актуальным
адресом исходников используемого форка: используйте вложенные материалы.

В runtime сохранены исходные JAR всех runtime-зависимостей точных версий.
Source JAR можно открыть обычным ZIP-архиватором. Для constraintlayout и
constraintlayout-solver 2.0.1 source JAR не опубликованы: приложен общий
исходный тег 2.0.1 официального androidx/constraintlayout.
Соответствие артефактов и файлов: RUNTIME_SOURCES.json.
