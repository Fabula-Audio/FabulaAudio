# FabulaAudio 4.8 fixed18 — changelog

## `app/src/main/java/com/fabula/audio/MainActivity.kt`

- Добавлена отдельная секция подготовки перед режимом ускорения.
- Добавлены настройки `Убрать щелчки`, `Убрать шумы`, `Коррекция АЧХ`.
- `Убрать щелчки` по умолчанию включён и использует `adeclick`.
- `Убрать шумы` по умолчанию включён и использует `afftdn=nr=<X>:nf=<Y>` непосредственно на оригинале.
- Ползунки шумоподавления: `nr` 0..24, по умолчанию 12; `nf` -60..-10, по умолчанию -25.
- Добавлено сохранение всех настроек подготовки в `SharedPreferences`.
- Шумоподавление после `x144` полностью удалено из основной цепочки.
- `Коррекция АЧХ` по умолчанию выключена; при включении применяется после щелчков и шума.
- Добавлено фоновое построение предпросмотра первых 20 секунд оригинала с текущими настройками подготовки.
- Изменение чекбокса или отпускание ползунка запускает пересборку предпросмотра с задержкой около 500 мс.
- Используется один общий `MediaPlayer`: новый запуск останавливает предыдущий; кнопка `Стоп` работает и для предпросмотра, и для готового результата.
- Основная цепочка сохранена: подготовка → `x6` → `x144` → `x432`.
- Каждый этап ускорения выполняется одним FFmpeg-вызовом с `-i` N раз и `concat=n=N:v=0:a=1`.
- После каждой конкатенации сохраняется `FABULA_DUR` и выполняется проверка разницы входной/выходной длительности не более 1 секунды.
- Сохранены `q()`, `check(ReturnCode.isSuccess(...))`, фоновый `Thread`, SAF и сохранение результата.

## `app/src/main/res/layout/activity_main.xml`

- Порядок экрана: выбор трека/папки → Подготовка → Режим обработки → Начать обработку → Результат → Громкость.
- Кнопки скорости переведены в равномерную сетку 2×2 с одинаковой высотой.
- Добавлена кнопка предпрослушивания подготовки.
- Удалён старый отдельный блок шумоподавления после обработки.
- Добавлены три чекбокса подготовки и два ползунка шумоподавления.
- Для поля названия сохранено `setSingleLine(true)`; свойства `singleLine = true` в Kotlin нет.

## Поведение шумоподавления

Артефакты типа «бульканья» можно уменьшить снижением `nr` или полным отключением `Убрать шумы`. Ползунок `nf` позволяет отдельно подобрать шумовой пол. Это инструмент пользовательской настройки характера звука, а не фиксированный «идеальный» пресет.
