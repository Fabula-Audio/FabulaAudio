# Сборка Fabula Audio 4.34 в Android Studio

1. Распакуйте ZIP в отдельную папку.
2. Android Studio → Open → выберите папку с settings.gradle.
3. Дождитесь Gradle Sync. Установите Android SDK 35, NDK 26.3.11579264,
   CMake 3.22.1 через SDK Manager. Gradle JDK: 17 или 21.
4. Проверочная сборка: Build → Build Bundle(s) / APK(s) → Build APK(s).
5. Для публикации: Build → Generate Signed Bundle / APK → APK.
   Выберите свой ключ подписи, alias и release. Не используйте debug APK для сайта.
6. Подписанный результат появится в выбранной при сборке папке.

Версия: 4.34, versionCode 35; Android 8.0 или новее, ARM64.
В «О приложении и лицензиях» есть кнопки «Исходный код» и «Лицензии».
Аудиообработка не менялась.

Ключ подписи и пароли храните отдельно от исходников и GitHub.
Сохраните резервную копию ключа: последующие обновления требуют той же подписи.
Если подпись прежней установленной версии отличается, обновление поверх неё
невозможно. Сначала экспортируйте важные записи, затем удалите старую версию.

Перед распространением APK опубликуйте соответствующие этой версии исходники:
https://github.com/Fabula-Audio/FabulaAudio
Архив исходников этой сборки также можно разместить рядом с APK на сайте.
Проверки текущего выпуска: VERIFICATION.txt; ограничения: SOURCE_STATUS.md.
