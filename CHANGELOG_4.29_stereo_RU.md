# Fabula Audio 4.29 — stereo recording

## Публикационная версия

- `versionName`: **4.29**
- `versionCode`: **29**
- GitHub Release tag: **v4.29**

## Изменения

### 1. Стереозапись аудио-заготовок

Изменён только `app/src/main/java/com/fabula/audio/RecordTextActivity.kt`.

На Android 12+ (`API 31+`) `MediaRecorder` явно получает:

```kotlin
setAudioChannels(2)
```

Запись остаётся в MPEG-4/AAC, 44.1 kHz, 128 kbps.

Для API ниже 31 сохранено системное поведение, чтобы не нарушать `minSdk 26`.

### 2. Сохранение в стерео

Существующая схема склейки и сохранения не переписывалась. Поскольку записываемые на поддерживаемом устройстве фрагменты теперь создаются как stereo AAC, существующая FFmpeg concat-схема сохраняет их stereo-канальность, а последующее копирование результата в SAF не меняет аудиопоток.

## Что НЕ менялось

- логика подготовки аудио;
- ×6 / ×144 / ×432;
- порядок и количество concat-копий;
- `MainActivity.kt`;
- `UpdateManager.kt`;
- `HomeActivity.kt`;
- `UiStyles.kt`;
- `file_paths.xml`;
- иконки и заставка;
- механизм SAF;
- логика автообновления;
- интерфейс режима записи.

## Конфигурация 4.29

В `app/build.gradle` сохранены изменения оптимизации 4.28:

- `ffmpeg-kit-audio:8.1.7` вместо `ffmpeg-kit-full:8.1.7`;
- `minifyEnabled true` для release;
- `shrinkResources true`;
- `proguard-rules.pro`;
- ABI: `armeabi-v7a`, `arm64-v8a`;
- `versionCode 29`;
- `versionName '4.29'`.

## Важное замечание о базе архива

Архив собран из последнего доступного в рабочем окружении полного проекта `FabulaAudio_Android_4.27_fixed33.zip` с применением предоставленной пользователем конфигурации оптимизации 4.28 и изменений 4.29.

Отдельного полного архива 4.28 в доступных файлах не было, поэтому изменения 4.28, не представленные исходниками, не реконструировались по догадке.
